# 全局工时管理功能用例与真实浏览器 E2E 场景

## 功能用例

### TC-F-001 BI 入口与布局一致
- 操作：从首页点击 `BI -> 全局工时`。
- 预期：页面使用 BI 标准顶部导航和 `#main/#mainContent` 布局，和 `BI -> 大屏` 的 app shell 一致。

### TC-F-002 不再展示分析维度下拉框
- 操作：打开全局工时页面。
- 预期：页面没有“分析维度”筛选项；固定展示总体指标、对象分布、停滞对象、人员分布、工时明细。

### TC-F-003 空间筛选-产品线/产品
- 操作：选择产品线或产品后筛选。
- 预期：总览、对象分布、停滞对象、人员分布、明细和导出均只包含该空间范围。

### TC-F-004 空间筛选-项目集/项目
- 操作：选择项目集或项目后筛选。
- 预期：所有指标和明细收敛到对应项目集或项目。

### TC-F-005 空间筛选-迭代
- 操作：选择迭代/执行后筛选。
- 预期：只统计该迭代/执行下的工时。

### TC-F-006 对象类型-业务需求
- 操作：对象类型选择业务需求。
- 预期：只统计 `objectType=epic` 的工时。

### TC-F-007 对象类型-用户需求
- 操作：对象类型选择用户需求。
- 预期：只统计 `objectType=requirement` 的工时。

### TC-F-008 对象类型-研发需求
- 操作：对象类型选择研发需求。
- 预期：只统计 `objectType=story` 的工时。

### TC-F-009 对象类型-Bug
- 操作：对象类型选择 Bug。
- 预期：只统计 `objectType=bug` 的工时。

### TC-F-010 对象类型-任务
- 操作：对象类型选择任务。
- 预期：只统计 `objectType=task` 的工时。

### TC-F-011 具体对象筛选
- 操作：选择对象类型并输入对象 ID。
- 预期：只统计该对象自己的工时；未勾选关联对象时不包含关联任务工时。

### TC-F-012 关联对象筛选
- 前置条件：需求关联了任务，任务上有工时。
- 操作：选择该需求对象 ID，并勾选“包含关联对象”。
- 预期：统计该需求自身工时和关联任务工时。

### TC-F-013 动态时间-本周
- 操作：时间范围选择本周。
- 预期：开始/结束日期落在当前自然周，统计只包含本周。

### TC-F-014 动态时间-本月
- 操作：时间范围选择本月。
- 预期：统计当前自然月。

### TC-F-015 动态时间-本季度
- 操作：时间范围选择本季度。
- 预期：统计当前自然季度。

### TC-F-016 自定义时间优先
- 操作：同时选择动态时间和自定义开始/结束日期。
- 预期：以自定义日期为准。

### TC-F-017 人员筛选-部门
- 操作：选择部门后筛选。
- 预期：只统计该部门成员的工时。

### TC-F-018 人员筛选-成员
- 操作：选择具体成员后筛选。
- 预期：只统计该成员工时。

### TC-F-019 总消耗工时
- 操作：打开页面查看总体指标。
- 预期：总消耗工时等于当前筛选范围内所有明细 `consumed` 求和。

### TC-F-020 实际/预估工时
- 前置条件：存在设置了预估工时的任务。
- 操作：打开页面查看总体指标。
- 预期：显示实际消耗工时/预估总工时，分母只包含有预估工时的对象。

### TC-F-021 研发对象分布比
- 操作：打开页面查看对象分布条。
- 预期：业务需求、用户需求、研发需求、Bug、任务、其他按工时比例显示为单条堆叠长条。

### TC-F-022 停滞对象阈值
- 前置条件：某对象两次工时记录间隔超过阈值。
- 操作：设置停滞阈值并筛选。
- 预期：停滞对象图展示该对象，条长等于停滞天数。

### TC-F-023 截止日停滞
- 前置条件：某对象最后一条工时记录到筛选结束日期超过阈值。
- 操作：设置停滞阈值并筛选。
- 预期：该对象进入停滞对象图。

### TC-F-024 人员工时分布
- 操作：打开页面查看人员工时分布。
- 预期：每个人一条横向堆叠条，右侧显示总工时，颜色段表示不同研发对象类别。

### TC-F-025 明细完整工作内容
- 操作：查看工时明细。
- 预期：工作内容可以完整查看，不只能看到截断文本。

### TC-F-026 明细二次过滤-日期
- 操作：在明细过滤中选择某一天。
- 预期：明细只保留该日期记录，总体图表不被二次过滤重算。

### TC-F-027 明细二次过滤-人员
- 操作：在明细过滤中选择人员。
- 预期：明细只保留该人员记录。

### TC-F-028 明细二次过滤-产品/项目
- 操作：在明细过滤中选择产品或项目。
- 预期：明细只保留该产品或项目记录。

### TC-F-029 CSV 导出
- 操作：设置全局筛选和明细二次过滤后导出 CSV。
- 预期：CSV 与当前明细一致。

### TC-F-030 空数据
- 操作：选择无工时范围。
- 预期：总体指标为 0，图表和明细显示空态，CSV 仅有表头。

## 真实浏览器 E2E 场景

### TC-E2E-001 BI 入口进入全局工时
- 浏览器操作：登录 admin，点击 `BI -> 全局工时`。
- 断言：页面标题为全局工时统计，BI 顶部导航可见，内容在 `#mainContent` 中。

### TC-E2E-002 对比大屏布局
- 浏览器操作：先打开 `BI -> 大屏`，再打开 `BI -> 全局工时`。
- 断言：两者都使用 48px BI header 和 1200px app 画布。

### TC-E2E-003 页面无分析维度
- 浏览器操作：打开全局工时。
- 断言：页面不存在“分析维度”下拉框。

### TC-E2E-004 空间筛选
- 浏览器操作：选择产品、项目、迭代后筛选。
- 断言：总览和明细收敛到筛选范围。

### TC-E2E-005 对象类型切换
- 浏览器操作：分别选择业务需求、用户需求、研发需求、Bug、任务。
- 断言：明细对象类型与选择一致。

### TC-E2E-006 关联对象勾选
- 浏览器操作：输入需求 ID，先不勾选关联对象，再勾选关联对象。
- 断言：勾选后关联任务工时进入明细。

### TC-E2E-007 动态时间筛选
- 浏览器操作：选择本周、本月、本季度。
- 断言：日期字段和明细记录均落在对应动态时间范围。

### TC-E2E-008 自定义时间筛选
- 浏览器操作：输入开始/结束日期后筛选。
- 断言：明细日期在范围内。

### TC-E2E-009 部门和成员筛选
- 浏览器操作：选择部门和成员。
- 断言：人员工时分布和明细只包含对应成员范围。

### TC-E2E-010 总体指标可见
- 浏览器操作：打开页面。
- 断言：总消耗工时、实际/预估工时、研发对象分布比可见。

### TC-E2E-011 研发对象分布条
- 浏览器操作：打开页面。
- 断言：分布条有多个颜色段，比例合计为 100%。

### TC-E2E-012 停滞对象图
- 浏览器操作：设置停滞阈值。
- 断言：停滞对象区展示对象名称/ID和停滞天数条。

### TC-E2E-013 人员工时堆叠条
- 浏览器操作：打开页面。
- 断言：人员分布以横向堆叠条展示，右侧显示总工时。

### TC-E2E-014 明细二次过滤
- 浏览器操作：在明细区选择日期、人员、产品、项目过滤。
- 断言：明细行收敛，页面总览不被二次过滤重算。

### TC-E2E-015 工作内容完整查看
- 浏览器操作：查看明细工作内容。
- 断言：长工作内容可完整查看。

### TC-E2E-016 CSV 导出一致
- 浏览器操作：设置筛选后点击导出 CSV。
- 断言：CSV 行数和字段与当前明细一致。

### TC-E2E-017 刷新保持状态
- 浏览器操作：设置筛选，刷新页面。
- 断言：筛选条件、BI 顶部导航和统计结果保持。

### TC-E2E-018 移动/窄窗口
- 浏览器操作：使用 780px 宽窗口打开页面。
- 断言：页面与 BI 原生 app shell 一致，图表和明细可滚动且不遮挡顶部导航。
